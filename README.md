Common Libraries 

------------------

Imaging - GIF, JPEG, KTX, etc Support. Animation.

Math - x86 optimized (intrinsics) Math functions, XMVECTOR Support, a lot of very useful functions, Shadertoy / GLSL style.

Noise - Bluenoise, various noise generation algorithms

Random - Random Number Generation, High Quality Uniform Random Numbers

Utility - Many single file header for abstract concepts that are implemented and some have been tested.

gltf - loader for gltf files, leverages
 * cgltf - a single-file glTF 2.0 parser written in C99.
 *
 * Version: 1.13
 *
 * Website: https://github.com/jkuhlmann/cgltf
 * See website for latest license details. MIT.
